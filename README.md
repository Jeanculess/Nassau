# Nassau ↔ Eleuthera

Pages autonomes pour le voyage (un seul fichier HTML chacune, données embarquées, rechargement en direct quand le réseau passe). Les pages publiées sont sur la branche [`page`](../../tree/page).

| Page | Lien direct |
|---|---|
| Cockpit du retour Cocodimama → Nassau | https://htmlpreview.github.io/?https://github.com/Jeanculess/Nassau/blob/page/retour.html |
| Prédicteur de soleil, Alabaster Bay | https://htmlpreview.github.io/?https://github.com/Jeanculess/Nassau/blob/page/ciel.html |
| Carnet de séjour Eleuthera | https://htmlpreview.github.io/?https://github.com/Jeanculess/Nassau/blob/page/eleuthera.html |
| Traversée aller Nassau → Eleuthera (18 octobre) | https://htmlpreview.github.io/?https://github.com/Jeanculess/Nassau/blob/page/index.html |
| Houlomètre | https://htmlpreview.github.io/?https://github.com/Jeanculess/Nassau/blob/page/houlometre.html |

Sur iPhone : ouvrir le lien dans Safari, puis Partager → « Sur l’écran d’accueil » pour l’avoir en plein écran. Le GPS et les données en direct fonctionnent par ces liens.

Pour un hébergement propre (`https://jeanculess.github.io/Nassau/retour.html`, installable hors ligne) : Settings → Pages → Source : GitHub Actions ; le workflow `.github/workflows/pages.yml` de la branche `page` publie alors tout.

Cette branche contient la source de la page de la traversée aller (`traversee-nassau-eleuthera.html`).
